# Catalyst CF Editor 1.0

## Español

Editor y cargador NAM/IR para Windows, con el Custom Firmware integrado en un
solo **CatalystCFEditor.exe**. Interfaz en español e inglés.

- Dos posiciones NAM A2 Lite y tres IR de pantalla.
- Instalación inicial con un botón y cinco ejemplos incluidos; copia verificada
  de los doce presets y comprobación del arranque después de reiniciar.
- Cambio individual de NAM/IR por USB sin reinstalar el firmware completo.
- Entrada NAM ajustable, inicialmente −5 dB; salida automática o manual,
  inicialmente manual a −3 dB.
- Conversión de IR decodificables a mono/48 kHz/2.048 muestras y cortes
  ajustables de 80 Hz / 8 kHz, con volumen automático o manual.
- Boost original y aproximaciones EP Boost, 808 y SD-1, efectos PRE/POST,
  presets, afinador y tempo.
- Conexión de datos corregida: consulta solo la posición elegida y evita
  duplicar lecturas costosas cuando el amplificador tarda en responder.

Si ya instalaste el CF incluido con esta revisión, esta corrección de conexión
requiere solo sustituir el EXE. No reinstales el firmware para corregir ese plazo.
Usuarios de CatalystIR o del firmware oficial: comienza por **FIRMWARE CF**.

Instalación habilitada para **Catalyst 60/CX60**. Los 100/200 no tienen pruebas
físicas y su instalación inicial permanece deshabilitada. Es experimental;
consulta [validación](https://github.com/conr4d86/Catalyst-CF-Editor/blob/main/docs/VALIDACION.md)
y [recuperación](https://github.com/conr4d86/Catalyst-CF-Editor/blob/main/docs/RECUPERACION.md).
El EXE no está firmado. Los hashes identifican los archivos distribuidos.

Descarga principal: **CatalystCFEditor.exe**. El ZIP Windows añade las guías y
avisos; el ZIP source es para desarrolladores. No necesitas compilar.

## English

A Windows amplifier editor and NAM/IR loader with Custom Firmware included in
one **CatalystCFEditor.exe**. Spanish and English interface.

- Two NAM A2 Lite positions and three cabinet IRs.
- One-button initial installation with five included examples, a verified
  twelve-preset backup and a startup check after restarting the amplifier.
- Individual NAM/IR uploads over USB without reinstalling the full firmware.
- Adjustable NAM input, default −5 dB; independent automatic/manual output,
  default manual −3 dB.
- Decodable IR conversion to mono/48 kHz/2,048 samples, adjustable 80 Hz / 8 kHz
  cuts and automatic/manual level.
- Factory Boost and original EP Boost, 808 and SD-1 approximations, PRE/POST
  effects, presets, tuner and tempo.
- Data connection fix: queries only the selected position and avoids queuing
  duplicate expensive scans when the amplifier needs more response time.

If you already installed this revision's included CF, replace the EXE only for
this connection fix. A firmware reinstall is not needed to change that deadline.
Users of CatalystIR or official firmware should start with **FIRMWARE CF**.

Initial installation is enabled for **Catalyst 60/CX60**. Physical 100/200 testing
is unavailable and their initial installation remains disabled. Experimental;
read the validation and recovery guides linked above. The EXE is unsigned.
Published hashes identify the distributed files.

Main download: **CatalystCFEditor.exe**. The Windows ZIP adds guides/notices;
the source ZIP is for developers. End users do not need to compile.
